TECHNICAL DEEP DIVE

From implementation to evidence.

Scoped queries and persistence boundaries

Controllers expose HTTP operations, services coordinate inventory and identity logic, DTOs shape responses, and generated MyBatis mappers remain separate from custom queries. Keyword search repeats warehouse and structured constraints in each OR branch so a broad text match cannot bypass the requested warehouse scope. Query values are bound; pagination uses PageHelper.

Authentication and authorization

Signed JWTs carry username, authority, issuer and a one-hour expiry. Validation preserves USER authority rather than promoting it to ADMIN, rejects invalid tokens before controller processing, and requires ADMIN for administrative writes. Password-change operations require the authenticated identity and old password; response serialization excludes password hashes and salts.

Audit storage and transaction boundaries

An AOP wrapper emits successful stock changes to a lock-protected 5,000-event ring and rolling JSONL output. History supports operation, user, stock and series filters. The query buffer is not restored on restart. Movement services use Spring transactions, but read-then-write stock quantities do not guarantee protection against concurrent overselling; audit delivery is not a transaction outbox.

What was verified

The public edition compiled 121 main Java files with Java 17 and passed 11 offline regression groups, covering JWT rejection and authority preservation, credential serialization, audit bounds/filtering, concurrent audit writes and malformed input. The Vue production build passed. Live MySQL/API integration and Maven/JUnit execution were not established by those offline checks.

04 / SCOPE & TRADEOFFS

Know what the result means.

Live MySQL/API integration is not yet validated. The audit query buffer is not restored after restart, and stock writes do not claim protection against concurrent overselling.
